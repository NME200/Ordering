# 多商户点餐小程序 · UI 界面设计说明

一套覆盖「外卖 / 门店自取 / 堂食点餐 / 排队叫号」四大场景的多商户点餐系统小程序界面，共 17 个页面（11 个主流程页 + 6 个分支功能页）。

---

## 一、设计系统（Design Tokens）

### 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 / 强调色 | `#C8752B` 暖橙 | 按钮、选中态、价格、主图标 |
| 辅助色 | 暖棕 | 标题文字、次级强调 |
| 页面背景 | `#FAF8F6` 极浅暖灰白 | 承载半透明卡片的透明层次 |
| 卡片 | 半透明白 + 毛玻璃模糊 | 透出下方暖灰底，不设重阴影 |
| 正文文字 | `#3A322C` | 主文案 |
| 次级文字 | `#9A908A` | 月售、时间、说明 |
| 分割线 | `#EFEBE7` 极细 1px | 无卡片页面的唯一分区手段 |

### 形状与间距

- 圆角：卡片 16px，按钮 24px（胶囊），弹层顶部 24px
- 卡片间距：8px（紧凑排布），区块间距 12px，页边距 16px
- 图标：统一 1.5px 细线线稿风格，线性、无填充

### 字体

中文黑体，标题 17px Bold / 正文 14px Regular / 次级 12px Regular / 数字与价格用等宽感排版。

### 全局规则

- 首页保持纯净：无顶部定位栏、无附近商户推荐位；多商户只在「查看门店」中出现
- 内容型页面（确认订单、订单列表、订单详情）**不使用白色卡片**，内容直接铺在背景上，仅用极细分割线分区
- 浏览型页面（首页、查看门店、点餐页、个人中心）使用半透明白毛玻璃卡片，间距紧凑

## 二、页面清单与流程

```
首页
 ├─ 门店自取 ─→ 查看门店 → 门店点餐页 → 规格弹层 → 购物车 → 确认订单 → 订单列表 → 订单详情
 ├─ 外卖     ─→ 查看门店 →（同上）
 ├─ 堂食点餐 ─→ 堂食点餐页（桌号 A12）→ 规格弹层 → 下单
 ├─ 排队叫号 ─→ 排队叫号页（取号 / 查看叫号进度）
 └─ 查看门店 ─→ 多商户列表 → 进店
底部导航：首页 / 订单 / 我的（个人中心）

分支功能页
 ├─ 收货地址管理 ← 确认订单「请选择配送地址」/ 个人中心「收货地址」
 ├─ 优惠券中心   ← 个人中心「领券中心」「我的优惠券」/ 确认订单「优惠券」
 ├─ 订单评价     ← 订单列表 / 订单详情「评价」
 ├─ 会员卡       ← 个人中心「会员卡」
 ├─ 发票管理     ← 个人中心「发票管理」
 └─ 在线客服     ← 个人中心「在线客服」/ 订单详情「客服」
```

## 三、页面详解

### 1. 首页

**入口**：小程序启动页
**结构**：
- 顶部品牌饮品摄影大图（白色纸杯咖啡 + 木质桌面，暖色调）

**交互**：点击任一入口进入对应流程；首页不放定位栏与商户推荐，保持纯净。

**入口**：个人中心 → 在线客服 ／ 订单详情 → 客服图标
**结构**：
- 顶部返回 + 标题「在线客服」+ 右侧更多图标
- 消息流：左侧客服头像 + 白色气泡「您好，旺卡咖啡在线客服小旺为您服务～」；右侧用户橙色气泡「我昨天那单还没送到」；左侧白色气泡「稍等，正在为您查询订单 202610071701380012」
- 中部半透明白订单小卡片：商品缩略图 + 名称「生椰拿铁 大杯/冰」+ ¥26.00 + 橙色文字「查看订单」
- 快捷问题胶囊：如何申请退款 / 配送超时怎么办 / 修改配送地址
- 底部输入栏：浅灰圆角输入框「请输入您的问题…」+「+」图标 + 橙色圆形发送按钮

**交互**：进入时自动带入当前订单上下文；机器人优先应答，转人工后显示客服昵称与工号；支持发图、发订单卡片、快捷问题一键发送。
